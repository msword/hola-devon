# Hola Devon Taco Truck

Hola Devon is a small taco truck business getting ready for a busy lunch service around North Devon.

The team wants to build a simple software system to help with menus, orders, stock, recipes, customers, and food safety checks. This repository is not finished yet. Your job is to help design the first version.

## Your Task

Choose one module from the `modules/` folder.

In that module file, add your ideas for:

1. **Attributes** - pieces of information the system should store.
2. **Functions** - actions the system might need to perform.

You do not need to write code today. Think like a developer planning the shape of the system before building it.

## Example

For a menu item, an attribute might be:

- `name`

A function might be:

- `change_price()`

## Modules

- `customer` - people who buy food from the taco truck.
- `inventory` - ingredients and stock levels.
- `item` - individual products that can be sold.
- `menu` - the list of food and drink available to customers.
- `order` - customer purchases.
- `recipe` - how food items are made.
- `safety` - checks that help the truck operate safely.
